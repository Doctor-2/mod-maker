# Routine trainer allowlist

The complete machine-readable event inventory is generated by
`tools/audit_routine_events.rb`. The runtime allowlist is intentionally smaller
than the set of syntactic candidates and contains only these manually reviewed
Map003 events:

| Map | Event | Trainer pages | Exact delegated effects |
|---:|---:|---|---|
| 3 | 1 | LASS Ellen v0/v1 | trainer prize formula; Reputation 10/15; self-switch A/B |
| 3 | 2 | YOUNGSTER Jeff v0/v1 | trainer prize formula; Reputation 10/15; self-switch A/B |
| 3 | 5 | PICNICKER Liz v0/v1 | trainer prize formula; Reputation 15/20; self-switch A/B |

Event 3 and 4 are item rewards and are preserved. Maps 4–6 contain the Cave of
Knowledge riddles, Ken recruitment, Lillith, and the starter/Charmander reward
chain; they are categorically protected. Every Gym, story, boss, gift, item,
transfer, common-event, and unknown battle remains outside the runtime allowlist.

The accepted command grammar is limited to dialogue, branches/loops, variable
and self-switch operations, and script lines. A syntactic candidate is never
automatically promoted to the runtime constant: promotion requires reviewing
all pages and recording the exact prize/Reputation/self-switch tuple above.
