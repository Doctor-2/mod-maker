# Independent review archive

Store returned independent blind reports here as immutable raw sources.

Rules:
- preserve the returned report verbatim;
- do not edit the raw report after saving it;
- record model/config/date when supplied by the user;
- keep factual audit/correction notes in a separate file;
- keep designer intent in a separate source file;
- do not replace the raw report with a later summary.

Suggested naming:
- `<YYYY-MM-DD>_<model>_BLIND_REPORT_RAW.md`
- `<YYYY-MM-DD>_<model>_BLIND_REPORT_AUDIT.md`
